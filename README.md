# YarraMate

YarraMate is an open-source semantic architecture engine and guided
methodology. It turns architecture into structured, testable context shared by
people and agents.

YarraMate owns a tool-neutral semantic graph, validates architectural claims
and rules, generates task-specific context and projections, and supports
incremental solution design through human and agent interfaces.

## Product boundaries

YarraMate Core is useful without any external modelling or graph tool:

- Native, versioned architecture documents are the committed source of truth.
- The semantic graph is compiled deterministically and regenerated by default.
- Core validation checks correctness, not architectural taste.
- A bundled native vocabulary can be extended through versioned profiles.
- Projections are semantic queries, not hand-maintained diagrams.
- The CLI is the stable interface for people, CI, and agent harnesses.

Integrations are optional:

- **LikeC4 adapter** — authoring and visualization.
- **Graphify adapter** — repository evidence and drift detection.
- **ArchiMate compatibility profile** — separately governed interoperability.

## Current foundation

The repository currently proves the semantic vocabulary through a LikeC4
adapter while the tool-neutral core is designed:

- `profile/specification.likec4` — current adapter vocabulary
- `profile/SEMANTICS.md` — semantic guidance
- `src/profile.ts` — machine-readable kind catalogue and relationship policies
- `schema/yarramate-document.schema.json` — normative native document schema
- `src/compiler.ts` — native loader and deterministic claim compiler
- `docs/NATIVE-DOCUMENT.md` — authoring, identity, graph, and diagnostic rules
- `test/profile.test.ts` — catalogue synchronization checks
- `examples/governed-change` — cross-layer example with a conditional path
- `docs/PRODUCT-CONTRACT.md` — agreed product and architecture contract
- `docs/ROADMAP.md` — staged delivery plan
- `docs/adr` — durable design decisions
- `docs/research` — primary-source research

## Current commands

```sh
pnpm install
pnpm build
pnpm validate
pnpm test
pnpm docs:dev
```

Check native documents through the stable CLI:

```sh
pnpm build
node dist/cli.js check architecture.yaml
node dist/cli.js check architecture.yaml --json
```

## Status

Version `0.1.0` is a validated foundation, not yet the complete YarraMate
engine. The next step is to define the native document schema and compiler
contract before implementing conformance.
