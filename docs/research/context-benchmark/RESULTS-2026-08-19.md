# Context benchmark — second sweep results (2026-08-19)

Status: human-adjudicated (adjudicator: nabsha, 2026-08-19). Protocol per
[DESIGN.md](DESIGN.md).
Negative and null results are reported with the same prominence as positive
ones.

## What this round is

The 2026-07-29 sweep ([RESULTS-2026-07-29.md](RESULTS-2026-07-29.md)) measured
`yarramate@0.4.0` and yielded four product root causes and five gallery pain
points. All were fixed across the 18 minor releases since; this round measures
whether the fixes moved the needle, on the v2 suites that were built to fix the
first sweep's own measurement gaps (saturated single-hop comprehension), plus
the first enterprise-scale cells (kafka, keycloak).

### Harness v3 deltas (PR #203) — comparability notes

1. The B/C instruction named `status` and `context`, verbs removed by the
   0.7.0 break; it now names `ask`, `check`, `reconcile`. B and C still share
   one byte-identical string. Consequence: B/C cells are not letter-for-letter
   the 2026-07-29 prompt; a fresh-vs-stale comparison within this sweep is
   unaffected, a B-vs-B comparison across sweeps carries this delta.
2. Catalogue snapshots now come from the pinned toolchain's own evaluator
   (`design --json`, shipped catalogue 0.8) instead of the research evaluator,
   whose schema had drifted behind the product. Consequence: catalogue-gate
   values are not comparable across sweeps; the not-worse delta within a run
   is.
3. runs.jsonl records toolchain version and gallery SHA; `--resume` skips
   recorded cells.

## Adjudication policy

1. Behavioral equivalence beats rubric letter; real behavioral gaps fail.
2. Incomplete answers fail (omitted required callers, pipeline steps, or
   named side paths).
3. A name or type mismatch that makes the change a no-op fails.
4. Extra unasked capability on an otherwise complete change fails. This
   scored the one draft-unclear cell (`mf-change-async-single-feed-refresh`
   haiku·C) as fail.
5. Zero runs excluded. All 276 comprehension and change cells are in the
   denominators.
6. Human accepted the six stream drafts in bulk on 2026-08-19 after
   reviewing clustered defect reasons. LLM drafts are not independently
   authoritative. Ground-truth disputes: 0. Condition-C `staleInfluence`: 0.

## Hypothesis verdicts

**H1 — context value: direction-consistent, still underpowered; load-bearing
on change.** Condition B is again the best cell at both tiers (haiku +8.7
pts, sonnet +10.9 pts over A). Pooled B−A is +9.8 pts (68/92 vs 59/92).
Every Wilson interval still overlaps. C sits between A and B; C ≥ A at
both tiers (+4.3 pts). The family split is the new fact: pooled change
B−A is +25.0 pts (19/28 vs 12/28), and sonnet change B is 13/14 against
8/14 in A. Pooled comprehension B−A is +3.1 pts; sonnet comprehension is
flat at 28/32. Honest verdict: same as 2026-07-29 on the pooled number —
suggestive, not significant — but the model is doing real work on edit
tasks, not on multi-hop reading.

**H2 — capability flattening: unsupported on adjudicated families; supported
only on the deterministic loop.** Sonnet leads haiku by +29.0 pts overall
(115/138 vs 75/138). The gap does not shrink in B (+30.4 pts) relative to
A (+28.3 pts). On change B it widens to +50.0 pts (13/14 vs 6/14). v2
multi-hop comprehension also stays tier-separated (sonnet 87.5% vs haiku
65.6% in B). Flattening continues to appear only where the deterministic
loop is the score: `check-pass` 24/24 both tiers; `no-contradicted` B 6/6
both. The 2026-07-29 wrinkle is now the result: the verifier levels tiers
only when the harness or task forces contact with it. Harder tasks without
that force do not flatten.

**H3 — trust sensitivity: unsupported at observed usage levels.** The
deliberately falsified model never dragged either tier below its no-model
baseline (C ≥ A in every pooled and per-tier cell). Zero `staleInfluence`
events in 92 C comprehension/change runs. Zero `groundTruthDispute`.
Maintenance sabotage repair is still rare and criterion-driven
(`no-contradicted` C: haiku 1/6, sonnet 2/6). The 2026-07-29 reframe
stands: the risk is not that stale models poison answers — it is that
models are not consulted enough for staleness to reach answers, and that
repair does not happen without an explicit gate.


## Threats to validity

- Harness v3 instruction delta (above) — cross-sweep B/C comparisons carry it.
- Claude Code CLI 2.1.220 → 2.1.235 between sweeps.
- Prior-knowledge contamination: kafka and keycloak are heavily represented in
  training corpora; comprehension passes there may not require the repo at all.
  (Same threat class as v1; the multi-hop task design mitigates, does not
  eliminate.)
- Catalogue gates measured with different evaluators across sweeps (v3 delta 2).
- One run per cell; n≈21/cell was already underpowered in v1 for H1-sized
  effects.
- Five httpie sonnet·C cells were replayed after a session-limit 429. The
  replayed cells used the same harness, suite, and gallery pin; they are
  later in wall-clock than the rest of the sonnet stream.
- Human accepted clustered drafts in bulk rather than a cell-by-cell
  Lavish pass; a later independent pass could flip singletons. The one
  unclear-to-fail call is recorded in the adjudication policy.
- v2 tasks are harder by design; absolute pass rates are not comparable
  to 2026-07-29.
