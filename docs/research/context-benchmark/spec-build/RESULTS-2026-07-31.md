# Spec-build family results (runs 1–3, 2026-07-31)

Status: complete family record, n = 3 per arm, Sonnet throughout,
deterministic scoring floor only — the human adjudication pass has not
happened, and per the no-LLM-judging rule these numbers are draft until
it does. Total spend across pilot + probes + runs 2–3 ≈ $56.

**The headline, stated honestly: on this well-specified task, the
pre-registered convergence hypotheses were NOT supported. The
A-converges-too guard fired — in the reversed direction.** Arm A (design
document) converged *more* than arm B (briefs from a checked model) on
both pre-registered measures. What survived, strongly, is the lie-
detection mechanism story. Both results are informative; neither is the
one we hoped for.

## Convergence (the pre-registered discriminators)

| Measure | Arm A | Arm B |
| --- | --- | --- |
| Design-name tokens, mean pairwise Jaccard | **0.595** (0.55–0.67) | 0.494 (0.40–0.58) |
| Build file paths, mean pairwise Jaccard | **0.261** (0.22–0.29) | 0.089 (0.07–0.13) |

- **H4 (B beats A on promise-keeping and convergence): not supported.**
  Promise-keeping saturated; convergence favours A.
- **H5 (B's runs agree more with each other): not supported; reversed.**
- The pre-registered guard — "if A converges as strongly as B, the spec
  is forcing the structure and the metric is uninformative" — **fired
  beyond its own wording**: A converged more, so the metric is telling
  us something, just not what H4/H5 predicted.

Two mechanisms behind the reversal, visible in the artifacts:

1. **B's design granularity is itself a free variable.** The three B
   designers declared 47, 44, and 27 planned concepts for the same spec.
   Arm A's prompt anchors its Components list (~15–17 every time), so
   A's vocabulary is stable by construction. Nothing in the designer-B
   prompt or the interrogate catalogue constrains granularity, and
   granularity variance dominates name-token Jaccard. This is a genuine
   product gap surfaced by the metric: **the model does not currently
   make two designers converge on how finely to model.**
2. **File-path Jaccard measures layout taste, not architecture.** The
   briefs name components but say nothing about directories; B's
   implementers each invented a layout (`src/services/*.js` vs
   `src/<service>/index.js` …). A's design documents apparently anchor
   layout more directly. A fairer structural-convergence measure would
   compare module dependency graphs, not paths — future work, noted
   before anyone re-scores.

## H6 across five lying builds

No lie of any variant reached code under this spec. The mechanism
ladder, now with three strong-dose consistent runs:

- Run 1 Cs (self-contradictory): caught on one sentence.
- Run 1 C (consistent bookkeeping): absorbed into the record silently —
  still the worst outcome observed.
- Run 1 Cc (consistent structural, minority dose): neither followed nor
  flagged; drowned by redundant truth; +30 turns.
- Runs 2 and 3 C (consistent structural, cross-source, strong dose):
  **caught by cross-brief redundancy** — both implementers compared the
  lied access/serving edges against the data objects' own truthful
  "Owned by …" lines and explicitly identified the cyclic shift
  ("cyclically shifted by one component relative to each data object's
  own stated owner"; "individually consistent but, taken together,
  contain a few internal contradictions"). Corrected, recorded, built
  true.

The emergent claim, sharper than the one we pre-registered: **every
truthful claim in a rich model is a witness against a lie.** To deceive
a careful reader you must co-rotate all correlated claims — ownership,
access, descriptions — and each addition to the model raises that bar.
The dangerous case remains the pilot's recorded boundary: lies where no
spec, tests, or redundant claims bear witness.

## What this family now says about the product

1. **Under a strong external spec, a checked model does not measurably
   beat a good design document on build convergence or promise-keeping**
   at Sonnet tier, n = 3. This rhymes with the 2026-07-29 sweep (models
   add least where ground truth is abundant) and should be said plainly
   in any pitch.
2. **The defensible value claims move to**: elicitation (the interrogate
   results), the audit/traceability record (arm C run 1's silent
   corruption is exactly what evidence/reconcile exists to catch), lie
   resistance through redundancy (this family's strongest new
   mechanism), and under-specified work where no conformance suite
   exists — which is untested here and is the family this design cannot
   reach.
3. **A granularity discipline is a real product gap**: two designers
   given the same spec produced 47- and 27-concept models. A catalogue
   wave or profile guidance about modeling depth would attack the
   variance that sank H5.

## Boundaries

One spec, one tier, one model family, three runs, deterministic floor
only, layout-agnostic briefs vs layout-bearing documents (a format
asymmetry we did not control), and run 1's C-family used earlier
injector variants (recorded per-run in `PROVENANCE.txt`). Human
adjudication of the eleven DEVIATIONS files and five lie records is the
step that converts any of this into publishable numbers.
