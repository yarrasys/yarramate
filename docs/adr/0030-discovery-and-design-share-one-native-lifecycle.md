# Discovery and design share one native lifecycle

Status: accepted

YarraMate treats existing-project discovery and architecture-first solution
design as two entry points into one native-document lifecycle. Both use the
stable CLI, produce reviewable proposals, become declared intent only through
Git acceptance, and later reconcile intent with evidence. This avoids a
second canonical discovered model or a privileged agent service while
preserving the essential distinction between observed evidence and authored
architecture.
