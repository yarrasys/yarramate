# Publication uses MIT and lightweight contributions

Status: accepted

YarraMate is published from `github.com/yarrasys/yarramate`. Code, schemas,
documentation, and the packaged agent skill use one MIT licence.

Contributors may use ordinary issues and pull requests. YarraMate does not
require a contributor licence agreement, Developer Certificate of Origin, or
commit sign-off. Git and the hosting platform retain contribution authorship
and review history.
