# Build semantics, not a notation clone

> Superseded in scope by ADR 0002. This decision remains as historical context
> for the initial LikeC4-backed foundation.

The initial prototype ports broad enterprise-architecture distinctions into
LikeC4 element kinds, relationship kinds, metadata, views, and catalogue
tests. It deliberately does not copy specification prose or claim external
language conformance.

ADR 0002 establishes that the production system is tool-neutral: LikeC4 is an
optional adapter, while exact external-language compatibility remains a
separately governed profile.
