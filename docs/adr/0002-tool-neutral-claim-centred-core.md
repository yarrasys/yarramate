# Establish a tool-neutral, claim-centred YarraMate Core

YarraMate Core owns a native, versioned document format and compiles it into a
tool-neutral semantic graph whose fundamental unit is a claim. The CLI is the
stable interface; Git supplies review and history; core validation enforces
correctness rather than completeness. LikeC4, Graphify, and external modelling
languages integrate through optional adapters or compatibility profiles and
do not define the core model.
